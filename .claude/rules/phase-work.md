---
description: Rules when working on build phases
globs: docs/BUILD_PLAN.md, docs/KNOWN_ISSUES.md
---

- Read `docs/BUILD_PLAN.md` before starting any phase work. Know the current phase and its gate.
- At phase end: run the hostile self-review (`.claude/skills/hostile-review.md`).
- Update `docs/KNOWN_ISSUES.md` with findings — both fixed items and deferred items.
- Pause for Matt's review. Do not start the next phase until he approves.
- The quality bar is in BUILD_PLAN §"Bamboo Beats quality". If it looks like a template with swapped copy, it isn't done.
